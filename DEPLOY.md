# Как поставить Misha Health Tracker на телефон

Приложение — это набор статических файлов. Чтобы установить его как приложение на iPhone
и получать напоминания, файлы нужно открыть по адресу `https://…` (не `file://` и не по локальной сети —
Safari не даст установить PWA и не покажет уведомления).

Ниже — два бесплатных способа выложить папку на `https://`, потом установка на телефон.

---

## Способ 1. Netlify (проще всего, без Git)

1. Открой **app.netlify.com**, зарегистрируйся (можно через Google/GitHub).
2. На главной → **Add new site** → **Deploy manually**.
3. Перетащи в окно **всю папку `misha-tracker`** целиком (не отдельные файлы).
   Файл `make-icons.html` можно предварительно удалить — он не нужен.
4. Через ~20 секунд появится адрес вида `https://random-name-123.netlify.app`.
   При желании его можно переименовать: **Site configuration → Change site name**.
5. Этот адрес и открывай на телефоне (раздел «Установка на iPhone» ниже).

**Обновить приложение позже:** снова зайти на сайт в Netlify → вкладка **Deploys** →
перетащить обновлённую папку. Адрес останется тот же.

## Способ 2. GitHub Pages

Локальный git-репозиторий уже создан: ветка `main`, первый коммит сделан,
приватные фото из `assets/source/` и `make-icons.html` в него НЕ попали (см. `.gitignore`).
Осталось создать репозиторий на GitHub и запушить.

1. На **github.com** → **New repository**. Имя: `misha-tracker`. Тип: **Public**
   (для бесплатного Pages). **Не** отмечай «Add a README / .gitignore / license» — репозиторий должен быть пустым.
2. В папке проекта выполни (подставь свой логин вместо `USERNAME`):
   ```
   git remote add origin https://github.com/USERNAME/misha-tracker.git
   git push -u origin main
   ```
   GitHub спросит логин и пароль — вместо пароля нужен **Personal Access Token**
   (github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) →
   Generate new token, галочка `repo`). Токен и вставляешь как пароль.
3. В репозитории на GitHub: **Settings → Pages → Build and deployment →
   Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты приложение будет по адресу `https://USERNAME.github.io/misha-tracker/`.
   Его и открывай на телефоне.

**Обновить приложение позже:**
```
git add -A
git commit -m "обновление"
git push
```
Pages переразвернётся сам за минуту.

(Все пути в приложении относительные, поэтому подпапка `/misha-tracker/` его не ломает.)

## Установка на iPhone

1. Открой адрес приложения в **Safari** (именно Safari, не Chrome).
2. Нажми кнопку **«Поделиться»** (квадрат со стрелкой вверх).
3. Выбери **«На экран „Домой"»** → **Добавить**.
4. Теперь на «Домой» есть иконка Миши. Запуск — на весь экран, работает и без интернета.

Если раньше уже добавляла старую версию — сначала удали её с «Домой» и добавь заново
(iOS намертво кэширует иконку).

## Напоминания о проверках

**Локальные уведомления (пока приложение открыто/свёрнуто):**
в приложении → **Профиль → «Включить напоминания на этом устройстве»** → разрешить уведомления.
Работает на iOS 16.4 и новее у установленного на «Домой» PWA. Приходят в 09:00 и 20:00
(время меняется в профиле), один мягкий повтор через 30 минут.

**Надёжные срабатывания по времени (даже когда приложение закрыто):**
в приложении → **Профиль → «Добавить напоминания в календарь»** → открыть скачанный файл `.ics` →
в Календаре iPhone появятся два повторяющихся ежедневных события с оповещениями.
На iPhone это надёжнее веб-уведомлений — рекомендуется сделать оба шага.

### Почему нет «настоящих» push-уведомлений

Push, когда сервер будит закрытое приложение, требует отдельного бэкенда (VAPID-ключи,
хранение подписок, планировщик рассылки). Здесь только статические файлы, сервера нет.
Для расписания «два раза в день» события в системном календаре закрывают эту задачу полностью.

## Данные

Всё хранится в браузере телефона (localStorage) и **не синхронизируется между устройствами**.
Перед сменой телефона или чисткой Safari: **Профиль → Данные → «Скачать резервную копию»**,
на новом устройстве — «Загрузить из копии».
